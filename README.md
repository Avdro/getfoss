# GetFOSS

**Free and open-source software, done right.**

GetFOSS is a curated directory and publication about free and open-source software (FOSS). We help people discover the best open-source applications for every platform, with a focus on privacy, security, transparency, and community-driven development.

## What is GetFOSS?

Finding trustworthy open-source software shouldn't be difficult. GetFOSS makes it easier by bringing useful FOSS applications, detailed articles, and practical recommendations together in one place.

Our goal is to help people make informed choices about the software they use every day.

## What We Cover

GetFOSS explores free and open-source software across a wide range of categories, including:

- Operating systems and Linux distributions
- Desktop applications
- Mobile applications
- Development tools
- Privacy and security
- Internet and networking
- Multimedia and creative software
- Productivity and office tools
- Self-hosted and server software
- Open-source games

## Our Principles

We believe software should respect its users and their freedom.

- **Free and open source:** We focus on software released under OSI-approved open-source licenses.
- **Privacy:** We value applications that respect user privacy and minimize unnecessary data collection.
- **Security:** We prioritize transparency, responsible development, and security-conscious software.
- **Community:** We appreciate projects built and maintained through open collaboration.
- **Quality:** We aim to highlight useful, reliable, and actively maintained applications.

GetFOSS does not promote proprietary software, closed-source freeware, or shareware.

## The Website

GetFOSS is built with [Astro](https://astro.build/) and uses a static-site architecture.

The website includes:

- Articles and software recommendations
- Category and tag archives
- Search powered by [Pagefind](https://pagefind.app/)
- RSS feed
- Multiple color themes
- Responsive design
