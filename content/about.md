# About GetFOSS

GetFOSS is an independent publication dedicated to free and open-source software, privacy, security, and digital freedom.

We explore software and technologies that give people greater control over the tools they use every day. Our focus is on practical open-source applications, Linux, privacy-respecting tools, security, self-hosting, and useful technologies worth knowing about.

GetFOSS aims to make open-source software easier to discover and understand. We publish straightforward guides, software overviews, practical recommendations, and explanations designed to help readers make informed choices about their technology.

The project is independent and focused on the open-source ecosystem, with an emphasis on useful software, transparency, user control, and digital freedom.

## What We Cover

- Free and open-source software (FOSS)
- Linux and open-source operating systems
- Privacy and security tools
- Open-source applications and utilities
- Self-hosting and decentralized technologies
- Practical guides and software recommendations
- Projects that promote user freedom and control

## Our Approach

We believe software should be understandable, transparent, and respectful of its users.

GetFOSS focuses on software that is useful in the real world—not simply because it is open source, but because it provides meaningful value, greater control, or a better alternative to proprietary solutions.
