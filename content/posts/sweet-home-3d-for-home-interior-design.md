Sweet Home 3D is a free interior design application for drawing the plan of a home in 2D, arranging furniture on it, and viewing the results in 3D. It is developed by Emmanuel Puybaret (eTeks) and aimed at people who want to design an interior quickly.

It runs as a desktop application on Windows, macOS and Linux, with installers bundled with Java. It is also available as Sweet Home 3D Mobile for iOS and Android, and as Sweet Home 3D Online in any browser supporting WebGL. The application is translated into 29 languages.

## Features

- **2D plan drawing** — Draw walls and rooms from scratch, or over the image of an existing plan, on one or more levels.
- **Furniture catalog** — Drag and drop doors, windows and furniture onto the plan from a catalog organized by categories, or import 3D models you created or downloaded from sites such as Trimble 3D Warehouse.
- **Customization** — Change the size, orientation, elevation, colors and textures of each piece of furniture, and apply custom colors and textures to walls, floors and ceilings, including imported images.
- **Live 3D view** — See plan changes simultaneously in a 3D view, navigable either from an aerial viewpoint or from a virtual visitor viewpoint.
- **Photorealistic rendering** — Create images based on the time of day and the light sources placed in the plan; version 7.0 introduced the faster YafaRay rendering engine.
- **Video creation** — Generate videos from a virtual path in the 3D view.
- **Plan annotations** — Add room areas, dimension lines, texts, arrows and a compass rose.
- **Export and printing** — Print the home plan and 3D view, or export to PDF, PNG, JPEG, SVG and OBJ formats for reuse in other software.
- **Plugins** — Extend the application with additional [plugins](https://www.sweethome3d.com/plugins/).

## FAQ

**Do I need Java installed to run the desktop version?**
No. The Windows, macOS and Linux installers come bundled with Java.

**How does the Online version differ from the desktop version?**
Features are similar, but homes are automatically saved on the website's server once you register. It has no menu bar — menu items are reachable from contextual menus or the toolbar — and it does not support 3D model import or photo and video creation.

**Can I import my own models?**
Yes, in the desktop version you can import 3D models you created yourself or downloaded from sites like Trimble 3D Warehouse.

**Is it available in my language?**
Sweet Home 3D is translated into 29 different languages.

## Alternatives

- **FreeCAD** — A general-purpose parametric CAD suite with architecture and BIM workbenches. Far more complex, aimed at engineering-grade design rather than quick interior layout.
- **LibreCAD** — A 2D-only CAD application. Suitable for technical floor plans, but it has no 3D view or furniture catalog.
- **Blender** — A full 3D creation suite that can model and render interiors in detail, but it has no 2D home-plan workflow or furniture catalog, with a much steeper learning curve.

## Pros and Cons

**Pros:**

- Free and open source, with desktop, mobile and browser versions
- 2D plan and 3D view update simultaneously while you work
- Importable 3D models and an extensible plugin system
- Export to standard formats (PDF, PNG, JPEG, SVG, OBJ)

**Cons:**

- Focused on interior layout rather than full CAD/BIM architectural work
- Online version lacks 3D model import and photo/video creation
- Mobile versions are distributed only through Apple's App Store and Google Play

## Installation and Getting Started

1. Download the installer for your platform from the [official download page](https://www.sweethome3d.com/download/):
  - **Windows**: run the downloaded setup program (84.9 MB) and follow the instructions of the setup wizard.
  - **macOS**: double-click the downloaded .dmg file (83.6 MB) and drag the application into the folder of your choice.
  - **Linux**: uncompress the downloaded archive (71.7 MB) and run the SweetHome3D application from the uncompressed directory; move the directory wherever you want to install it.
2. On iOS or Android, install Sweet Home 3D Mobile from Apple's App Store or Google Play.
3. To work in a browser instead, open [Sweet Home 3D Online](https://www.sweethome3d.com/online-manager/) on any device supporting WebGL; homes are saved on the server once you register.

To get started, draw walls or import the image of an existing plan, drag furniture from the catalog onto the plan, and switch to the 3D view to inspect the result. The [user's guide](https://www.sweethome3d.com/users-guide/) covers the workflow in detail.
