# Contact GetFOSS

Have a question, suggestion, correction, or feedback? You can get in touch with the GetFOSS project through GitHub.

## GitHub

For general questions, suggestions, bug reports, corrections, or ideas related to GetFOSS, visit the project repository:

[GetFOSS on GitHub](https://github.com/Avdro/getfoss)

You can open an issue there if you have found an error, want to suggest a topic, or have feedback about the website or its content.

## Content Corrections

If you notice an outdated, inaccurate, or incorrect piece of information in an article, please let us know through GitHub. Include the article title and a short explanation of the issue so it can be reviewed.

## Open Source Contributions

GetFOSS is an open-source project. Contributions, improvements, corrections, and suggestions are welcome.

The source code, website configuration, and project files are available in the GitHub repository.

[Visit the GetFOSS repository](https://github.com/Avdro/getfoss)
